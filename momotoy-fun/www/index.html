玩偶丢失了 NFC 标签怎么办?

联系客服提供购买凭证,可补办同款 NFC 标签,数据完全迁移,绑定到新标签后老标签自动失效。

AI 对话额度用完怎么办?

系统赠送 6 个月基础对话额度,到期前 7 天会有站内提示。续费 ¥29/月,可随时取消。

数据能导出 / 迁移到其他平台吗?

可以。个人中心 → 数据导出,生成包含全部养成记录的 JSON 包,可在任意 MomoToys 实例导入。

有开放 API 吗?

标准装起送用户可申请个人 API Key,用于自建第三方工具。详细文档见 GitHub 公开仓库。
